# Logo maskapai

Taruh logo di folder ini. Nama file mengikuti `slug` di `src/lib/map3d/departures.ts`:

| Maskapai | Nama file |
|---|---|
| Garuda Indonesia | `garuda-indonesia.svg` |
| Citilink | `citilink.svg` |
| Pelita Air | `pelita-air.svg` |
| Batik Air | `batik-air.svg` |
| Sriwijaya Air | `sriwijaya-air.svg` |
| Super Air Jet | `super-air-jet.svg` |
| Susi Air | `susi-air.svg` |
| Lion Air | `lion-air.svg` |
| TransNusa | `transnusa.svg` |

Format yang dibaca, berurutan: `.svg`, `.png`, `.webp`. Rasio kira-kira 2:1 (lebar:tinggi), latar transparan lebih baik.
Selama file belum ada, daftar Departure menampilkan inisial maskapai.

Logo adalah merek dagang masing-masing maskapai. Pakai file resmi dari mereka dan pastikan izin penggunaannya.
